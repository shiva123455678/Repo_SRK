# Python Calculator

A simple command-line calculator for basic and advanced arithmetic operations.

## Features

- ➕ Basic arithmetic: `+`, `-`, `*`, `/`
- 🔧 Advanced operations: `**` (exponent), `//` (floor division), `%` (modulo)
- 🛡️ Error handling for invalid input and division by zero
- 🎯 Interactive command-line interface

## Usage

```bash
python3 calculator.py
```

Then enter expressions:
```
>>> 5 + 3
= 8

>>> 10 * 2
= 20

>>> 2 ** 8
= 256

>>> exit
```

## Supported Operations

| Operation | Symbol | Example |
|-----------|--------|---------|
| Addition | `+` | `5 + 3` → 8 |
| Subtraction | `-` | `10 - 4` → 6 |
| Multiplication | `*` | `7 * 8` → 56 |
| Division | `/` | `20 / 4` → 5.0 |
| Floor Division | `//` | `17 // 5` → 3 |
| Modulo | `%` | `17 % 5` → 2 |
| Exponentiation | `**` | `2 ** 3` → 8 |
